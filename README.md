# 🏥 SGHSS – Sistema de Gestão Hospitalar e de Serviços de Saúde

O **SGHSS (Sistema de Gestão Hospitalar e de Serviços de Saúde)** é um projeto acadêmico e prático focado na organização e simulação de fluxos hospitalares, com ênfase em **desenvolvimento front-end e lógica de sistemas**, voltado para estudo, portfólio e demonstração técnica.

O sistema foi desenvolvido como parte do curso de **Análise e Desenvolvimento de Sistemas**, com foco em boas práticas de estruturação de projetos, organização de interfaces e simulação de funcionalidades reais da área da saúde.

---

## 🎯 Objetivo do Projeto

* Simular o funcionamento de um sistema hospitalar
* Organizar fluxos como atendimento, agendamento e gestão de serviços
* Aplicar conceitos de desenvolvimento de sistemas
* Servir como projeto de portfólio para vagas de tecnologia

---

## 🧩 Funcionalidades Simuladas

* 📅 Agendamento de consultas
* 🧑‍⚕️ Gestão de pacientes
* 🏥 Organização de serviços hospitalares
* 📋 Interfaces para navegação entre módulos do sistema

> Obs.: O projeto utiliza **dados simulados**, sem persistência em banco de dados.
